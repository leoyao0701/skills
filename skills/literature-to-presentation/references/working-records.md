# 按需使用的工作底稿

以下是字段模板，使用时填写实际内容；不必生成所有表格，也不要求把内部记录放进演示页。

## 来源记录

| 字段 | 记录内容 |
|---|---|
| source_id | 稳定标识，用于连接正文、讲稿和备注 |
| citation | 作者、作品、版本、年份和出版信息 |
| access | 本地原书、正式全文、节选、摘要、书评、转录等 |
| locator | 印刷页／PDF页／章节／条款；记录版本判断依据 |
| excerpt | 核对过的原文；保留关键限定 |
| translation | 需要时记录译文与译者身份 |
| supported_claims | 此处直接支持的命题 |
| limits | 未读范围、不能由此推出的主张、待核疑点 |
| url_or_file | 实际核查入口；发布时清理本机和私有信息 |

## 页面底稿

| 字段 | 记录内容 |
|---|---|
| slide_id / topic_id | 物理页与讲述主题的对应关系 |
| claim | 这一页的统摄性命题 |
| attribution | 原书、后续文献、历史事实或报告者综合 |
| evidence | 来源标识与准确定位 |
| relation | 并列、比较、条件、因果、时间、矩阵、层级或例证 |
| visual | 与上述关系对应的组件及必要标签 |
| prose | 可独立理解的完整页面文字 |
| script | 主讲、转场与补充解释 |
| first_mentions | 作者、理论、英文与易混淆词 |
| image | 来源、性质、时间、署名和使用条件 |
| timing | 预计时长与主讲／备份属性 |

## 修订与审计记录

| 页码/来源 | 问题 | 类型 | 核查依据 | 修改及同步范围 | 复核状态 |
|---|---|---|---|---|---|
| 实际对象 | 明确写出问题 | 实质错误／证据不足／措辞歧义／视觉误导／可选优化 | 原文位置或实际渲染 | 正文、讲稿、备注、来源等 | 已解决或具体限制 |

状态应可复核。不能以“已处理”替代实际修改，也不把未取得全文标成全文核验。
